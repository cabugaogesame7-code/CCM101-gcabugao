# Laboratory 01 – Welcome to the Cloud
## Mission Overview
This activity introduced me to Linux and the basic tasks used in cloud work. I used KillerCoda to run commands and GitHub to store my portfolio.

## Objectives
- Access Linux through KillerCoda.
- Learn basic navigation and system commands.
- Check OS, memory, and storage details.
- Create and organize folders and files.
- Set up a GitHub repository.
- Use Markdown for documentation.

## Activities Performed
- Accessed KillerCoda terminal.
- Created a new user and gave it permissions.
- Ran commands to check identity and system data.
- Made directories and files from scratch.
- Copied work into the portfolio structure.
- Prepared files for GitHub upload.
